## Environment

- **Dev server** (web + API): see `docs/development.md`:
  `LAMASYNC_API_KEY=dev-key LAMASYNC_DATA_DIR=/tmp/lamasync-test
  LAMASYNC_BACKUP_DIR=/tmp/lamasync-test-backups bun run dev:server`.
- **Browser sizes**: 360px / 768px / 1440px (devtools or agent-browser
  `setViewport`). Light AND dark themes.
- **TUI captures**: a real PTY (tmux `new-session` → `capture-pane -p -S -32
  > tui/<name>.txt`), sizes 80×24 and 120×40 (and a degraded 60×20 for the
  help-clamping check). `LAMASYNC_DEBUG_KEYS=1` prints key events if a
  hotkey seems unresponsive.
- **Real sync/backup exercises** need rclone + a configured folder on the
  host; never install rclone inside a worktree (system tool).
- Empty-fleet captures use the dev server with no hosts registered; add a
  handful of fake rows for populated views (see existing artifacts).
